# Link rot report

**480 dead external URLs remain, cited 574 times.** Updated 2026-09-18. Every link below is one where the vendor removed the page and no successor page covers the same thing, so there was nothing true to point it at.

## What happened

The external link check in `link-check.yml` had never run (see CHANGELOG 2026-09-17). Once it did, sweeps on 2026-09-17 and 2026-09-18 checked every one of the 8,500+ unique external URLs in the tree for three kinds of death, not just one:

- **Hard 404** - the vendor says the page is gone.
- **Soft 404** - the server answers 200 but the page says "not found". No status-code checker can see these, lychee included. Mostly IBM Cloud docs.
- **Deep link lost to a redirect** - the URL now forwards to a homepage, search page or login wall, so the reader lands somewhere that is not the cited page.

That found **783 dead URLs**. **303 were repaired, covering 449 citations.** Separately, 37 links that had moved rather than disappeared were pointed straight at their new home, 87 citations: dead hosts with a known successor (`home.pearsonvue.com`, `spec.modelcontextprotocol.io`, `forsetisecurity.org`) and links that only still worked through a redirect (AWS doc indexes, product renames such as Vertex AI's). Each replacement was fetched and returned 200 on a page whose title matches the citation. Candidates came from the vendor's own navigation, sitemaps or search, and were chosen by reading them, never by a similarity score alone. Scores kept matching the wrong product (Open Catalog for Snowflake, Cassandra for Cosmos DB NoSQL, a different Catalyst switch), and every one of those was rejected.

## How to fix one

If the vendor published a successor, replace the URL. If the product or feature is retired, the citation is usually telling you the *content* around it is stale too, and that is worth more attention than the link. **Fallback**, where shown, is a live landing page in the same product's docs, verified 200. It is a last resort, not a fix.

URLs are written as code rather than links so the link checker does not report this file back to itself.

## Retired products pointed at their successor

Where the vendor retired a product and names an official successor, the citation now points at the successor's docs, although the link text still names the old product. If the surrounding content describes the retired product in detail, the content needs revising, not just the link.
