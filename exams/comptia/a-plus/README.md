# CompTIA A+ (220-1201 and 220-1202)

## Exam Overview

CompTIA A+ is the entry-level certification for IT support work. It proves you can build, configure, and fix PCs, laptops, mobile devices, printers, and small networks, and that you can support Windows, macOS, and Linux users safely and professionally. It is the most common first certification for help desk, desktop support, and field technician roles, and it is approved by the US Department of Defense for Directive 8140 roles.

A+ is two exams, not one. You must pass **Core 1 (220-1201)** and **Core 2 (220-1202)**, and both must come from the same exam series. The current series is called **V15**. It launched on March 25, 2025 and replaced the V14 series (220-1101 and 220-1102), which CompTIA retired in September 2025.

**What changed from V14:** two changes are visible straight from the V15 objectives documents. Core 2 gained an AI objective (4.10 - integration, policy, bias, hallucinations, private vs public models). And CompTIA moved the troubleshooting methodology out of the tested Core 1 objectives. It is still printed in the objectives document as a job competency, and every troubleshooting question still assumes you think that way. For a line-by-line comparison, see Professor Messer's diff pages linked in [the strategy page](strategy.md#study-resources).

## Quick Reference

| Item | Core 1 (220-1201) | Core 2 (220-1202) |
|------|-------------------|-------------------|
| **Focus** | Hardware, mobile devices, networking, virtualization and cloud, hardware and network troubleshooting | Operating systems, security, software troubleshooting, operational procedures |
| **Duration** | 90 minutes | 90 minutes |
| **Questions** | Maximum of 90 | Maximum of 90 |
| **Question types** | Multiple choice (single and multiple response), drag-and-drop, performance-based | Same |
| **Passing score** | **675** (scale of 100-900) | **700** (scale of 100-900) |
| **Launched** | March 25, 2025 | March 25, 2025 |
| **Expected retirement** | Estimated 2028 (CompTIA says "usually three years after launch") | Estimated 2028 |
| **Languages** | English, German, Japanese | English, German, Japanese |
| **Recommended experience** | 12 months hands-on in an IT support specialist role | Same |
| **Prerequisites** | None | None |
| **Delivery** | Pearson VUE test center or online proctored | Same |
| **Validity** | 3 years from the date you pass the second exam, renewable through CompTIA CE | Same |

**Cost:** one voucher per exam, so two vouchers for the certification. CompTIA's product pages load the price per region and did not expose a verifiable USD figure when this page was written (2026-09-28). Third-party guides in 2026 quote roughly $246 to $274 USD per exam. Check the CompTIA store for your country before budgeting. See [the fact sheet](fact-sheet.md#quick-reference) for the full list of what was and was not verified.

## Domain Summary

### Core 1 Domain 1: Mobile Devices (13%)
Replacing laptop and phone parts (battery, keyboard, RAM, SSD, wireless card, webcam, antenna), connection methods (USB-C, Lightning, NFC, Bluetooth, tethering, hotspot), docking stations and port replicators, cellular data, SIM and eSIM, Bluetooth pairing, location services, MDM, BYOD, and synchronization.

### Core 1 Domain 2: Networking (23%)
The fourteen ports you must know by heart, TCP vs UDP, Wi-Fi frequencies, channels and 802.11 standards, server roles (DNS, DHCP, file, print, mail, syslog, AAA, NTP), DNS record types and email authentication (SPF, DKIM, DMARC), DHCP scopes and reservations, VLANs and VPNs, networking hardware, PoE, SOHO IP addressing, internet connection types, network types, and cabling tools.

### Core 1 Domain 3: Hardware (25%)
Display types and attributes, cable and connector types, RAM form factors and channels, storage devices and RAID levels, motherboard form factors, CPU sockets and architectures, BIOS/UEFI settings, TPM and HSM, cooling, power supplies, multifunction printer deployment, and maintenance for laser, inkjet, thermal, and impact printers.

### Core 1 Domain 4: Virtualization and Cloud Computing (11%)
Why we use virtual machines, Type 1 vs Type 2 hypervisors, containers, VDI, resource requirements, cloud deployment models (public, private, hybrid, community), service models (IaaS, PaaS, SaaS), and cloud characteristics such as elasticity, metered use, and multitenancy.

### Core 1 Domain 5: Hardware and Network Troubleshooting (28%)
The heaviest Core 1 domain. Symptom-to-cause matching for motherboards, RAM, CPUs, power, drives and RAID arrays, displays and projectors, mobile devices, networks, and printers.

### Core 2 Domain 1: Operating Systems (28%)
OS types and filesystems, installation and upgrade methods, GPT vs MBR, Windows 10 and 11 editions, Windows GUI tools and MMC snap-ins, the Windows command line, Settings and Control Panel, Windows networking, macOS features, Linux commands and config files, application requirements, and cloud productivity tools.

### Core 2 Domain 2: Security (28%)
Physical and logical security controls, Windows security settings (Defender, firewall, BitLocker, NTFS vs share permissions, Active Directory basics), wireless security and authentication protocols, malware and removal tools, social engineering, the 10-step malware removal procedure, workstation and mobile hardening, data destruction, SOHO router security, and browser security.

### Core 2 Domain 3: Software Troubleshooting (23%)
Windows problems (BSOD, boot failures, slow performance, services not starting, time drift), mobile OS and app problems, mobile security issues (jailbreaks, sideloading, unusual data usage), and PC security symptoms (pop-ups, redirects, certificate warnings, renamed files).

### Core 2 Domain 4: Operational Procedures (21%)
Ticketing and documentation, asset management, change management, backup types and rotation schemes, safety (ESD, electrical, lifting), environmental controls, incident response and licensing, professionalism, scripting file types, remote access tools, and basic AI concepts.

## Lab Setup

A+ rewards hands-on time more than any other entry-level cert. The PBQs ask you to drag cables to ports, pick commands, set BIOS options, and configure SOHO routers.

- **An old desktop** - Take it apart and put it back together. Reseat RAM, swap a drive, clear CMOS, change the boot order, and enable virtualization in UEFI.
- **Windows 11 VM** - Hyper-V (Windows Pro) or VirtualBox. Practice every MMC snap-in and command in [the OS notes](notes/06-operating-systems.md).
- **Linux VM or WSL** - Ubuntu or Fedora. Run the Linux commands until they are muscle memory.
- **A SOHO router** - Change the admin password, set WPA3, create a guest network, add a DHCP reservation, and forward a port.
- **A multimeter and a cable tester** - Cheap, and they make the tools questions easy.
