# OCI AI Foundations Associate (1Z0-1122-25)

Oracle's entry-level AI certification: AI and machine learning fundamentals, deep learning concepts, generative AI, and the OCI AI service portfolio.

This closes a real gap. The repo carried five Oracle OCI certifications and **no Oracle AI certification**, in a repository whose subject is cloud plus AI.

## Exam Details

- **Exam Code:** 1Z0-1122-25
- **Duration:** 60 minutes
- **Questions:** 40, multiple choice
- **Passing Score:** 65%
- **Cost:** USD 245 list; Oracle runs free certification windows for its AI exams regularly
- **Prerequisites:** None
- **Format:** Knowledge-based, no coding

Full detail in the [fact sheet](./fact-sheet.md).

## What the exam is like

Short and broad: 40 questions in 60 minutes at a 65% pass mark, which is 26 correct. It tests recognition and vocabulary rather than depth.

Two things carry most of the marks:

1. **Concept definitions.** Supervised versus unsupervised, classification versus regression, overfitting versus underfitting, precision versus recall.
2. **Service selection.** Given a business need, which OCI AI service fits. The table in the [fact sheet](./fact-sheet.md#the-service-selection-table) is worth memorizing outright.

## A note on free training

Oracle University publishes the full learning path for this certification free, and Oracle periodically makes the exam itself free. If a free window is open, this is among the cheapest vendor AI credentials available. Check before paying list price.

## Study sequence

1. AI, ML, and deep learning fundamentals, which is most of the conceptual weight
2. Generative AI and LLM concepts
3. The OCI service portfolio, drilled until service selection is automatic
4. Practice questions
